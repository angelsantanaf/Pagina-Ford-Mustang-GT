# 🏎️ Página inicial — Ford Mustang GT: O Ícone dos Muscle Cars

> *"O puro espírito dos muscle cars americanos em uma experiência web moderna, imersiva e de alta performance."*

---

## 🏎️ Sobre o Projeto

Este projeto consiste em uma **Landing Page moderna e responsiva** desenvolvida para a apresentação e divulgação do lendário **Ford Mustang GT**.

O objetivo principal foi aplicar princípios fundamentais de **UI/UX Design** e **desenvolvimento Web**, criando uma interface marcante e elegante que reflete o poder e a esportividade do modelo, combinando clareza visual, tipografia marcante e focada bem estruturada com especificações técnicas e tabelas de desempenho.

---

## 🛠️ Tecnologias Utilizadas

* 🟧 **HTML5:** Estrutura semântica avançada (`<article>`, `<header>`, `<section>`, `<table>`), acessibilidade básica e organização de dados em tabelas.
* 🟦 **CSS3:** Estilização responsiva, layout moderno (Flexbox/Grid), paleta de cores esportivas e efeitos visuais imersivos.
* 🎨 **Conceitos de UI/UX:** Hierarquia visual marcante, tipografia legível, direcionada para destaque do produto e chamadas para ação (CTAs) estratégicas.

---

## ⚡ Destaques do Projeto

* 🏎️ **Design Imersivo:** Layout agressivo e elegante, planejado para transmitir o visual e o ronco do inconfundível motor Coyote V8.
* 📱 **Layout Responsivo:** Adaptável e otimizado para dispositivos móveis, tablets e desktops.
* 📊 **Tabelas & Especificações:** Estrutura rica em detalhes com dimensões, dados de desempenho do motor 5.0L V8 e itens exclusivos da versão GT.
* 🎯 **Foco em Conversão & Leitura:** Organização estratégica das informações, com destaque para a imagem principal, lista de características e chamada para ação.
